## プロジェクト概要

Firebase と GCP を活用したモダンなテトリス Web ゲームの開発プロジェクト。

### 主な特徴

- ブラウザベースのリアルタイムテトリスゲーム
- Firebase Authentication によるユーザー認証
- Firestore によるスコア・ランキング管理
- Firebase Hosting によるデプロイ
- レスポンシブデザイン対応
