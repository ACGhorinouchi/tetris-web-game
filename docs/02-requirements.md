# 02. 要件定義

## 2.1 機能要件

### 2.1.1 ゲームコア機能

| ID | 機能名 | 説明 | 優先度 |
|----|-------|------|--------|
| F-001 | テトリミノ生成 | 7種類のテトリミノをランダムに生成 | 必須 |
| F-002 | テトリミノ移動 | 左右移動・落下操作 | 必須 |
| F-003 | テトリミノ回転 | 時計回り/反時計回り回転 | 必須 |
| F-004 | ハードドロップ | 即時落下機能 | 必須 |
| F-005 | ライン消去 | 揃った行の消去とスコア加算 | 必須 |
| F-006 | ゴーストピース | 落下位置のプレビュー表示 | 推奨 |
| F-007 | ネクスト表示 | 次のテトリミノを表示 | 必須 |
| F-008 | ホールド機能 | テトリミノの一時保持 | 推奨 |
| F-009 | レベルシステム | ライン消去に応じた難易度上昇 | 必須 |
| F-010 | ゲームオーバー判定 | 積み上がり時の終了処理 | 必須 |

### 2.1.2 ユーザー機能

| ID | 機能名 | 説明 | 優先度 |
|----|-------|------|--------|
| U-001 | 匿名認証 | ゲスト状態でのプレイ | 必須 |
| U-002 | Google認証 | Googleアカウントでログイン | 推奨 |
| U-003 | プロフィール表示 | ユーザー名・アバター表示 | 推奨 |
| U-004 | ログアウト | 認証状態の解除 | 必須 |

### 2.1.3 スコア・ランキング機能

| ID | 機能名 | 説明 | 優先度 |
|----|-------|------|--------|
| S-001 | スコア計算 | ライン消去・コンボによるスコア計算 | 必須 |
| S-002 | スコア保存 | ゲーム終了時のスコアをFirestoreに保存 | 必須 |
| S-003 | ハイスコア表示 | 個人のハイスコア表示 | 必須 |
| S-004 | グローバルランキング | 全ユーザーのトップ10表示 | 必須 |
| S-005 | リアルタイム更新 | ランキングのリアルタイム反映 | 推奨 |

### 2.1.4 UI/UX機能

| ID | 機能名 | 説明 | 優先度 |
|----|-------|------|--------|
| X-001 | レスポンシブデザイン | PC/タブレット/モバイル対応 | 必須 |
| X-002 | キーボード操作 | 矢印キー/スペースキーでの操作 | 必須 |
| X-003 | タッチ操作 | スワイプ/タップでの操作 | 推奨 |
| X-004 | 一時停止 | ゲーム中断・再開機能 | 必須 |
| X-005 | BGM/SE | ゲーム音楽・効果音 | オプション |
| X-006 | ダークモード | 表示モード切替 | オプション |

## 2.2 非機能要件

### 2.2.1 パフォーマンス

| 項目 | 要件 |
|-----|------|
| フレームレート | 60fps を維持 |
| 初期ロード時間 | 3秒以内 |
| 入力遅延 | 16ms以内（1フレーム） |

### 2.2.2 可用性

| 項目 | 要件 |
|-----|------|
| 稼働率 | Firebase Hosting の SLA に準拠 |
| オフライン対応 | ゲームプレイはオフラインでも可能（スコア保存は不可） |

### 2.2.3 セキュリティ

| 項目 | 要件 |
|-----|------|
| 認証 | Firebase Authentication による安全な認証 |
| データ保護 | Firestore Security Rules による適切なアクセス制御 |
| スコア改ざん防止 | クライアントサイドでの基本的な検証 |

### 2.2.4 互換性

| ブラウザ | 最低バージョン |
|---------|--------------|
| Chrome | 90+ |
| Firefox | 88+ |
| Safari | 14+ |
| Edge | 90+ |
