# 01. プロジェクト概要

## 1.1 プロジェクト名

**テトリス Web ゲーム (Tetris Web Game)**

## 1.2 目的

ブラウザ上で動作するテトリスゲームを開発し、Firebase/GCP インフラを活用してスケーラブルなゲームプラットフォームを構築する。

## 1.3 背景

- モダンな Web 技術を活用したゲーム開発の学習
- Firebase エコシステムの実践的な活用
- リアルタイムランキングシステムの実装経験

## 1.4 スコープ

### 1.4.1 スコープ内

- テトリスゲームのコアロジック実装
- ユーザー認証機能（匿名認証/Google認証）
- スコア記録・ランキング機能
- レスポンシブ UI
- Firebase Hosting へのデプロイ

### 1.4.2 スコープ外

- マルチプレイヤー対戦機能（将来の拡張として検討）
- モバイルアプリ版
- 課金機能

## 1.5 成功基準

1. テトリスゲームが正常にプレイ可能
2. スコアがリアルタイムで保存・表示される
3. グローバルランキングが正しく表示される
4. レスポンシブデザインでPC/モバイル両対応
5. Firebase Hosting で公開可能

## 1.6 ステークホルダー

| 役割 | 責任 |
|-----|------|
| 開発者 | 設計・実装・テスト・デプロイ |
| エンドユーザー | ゲームプレイ・フィードバック |

## 1.7 制約条件

- Firebase 無料枠（Spark プラン）での運用を想定
- ブラウザ互換性: Chrome, Firefox, Safari, Edge の最新版
